# Third-Party Data, Models and Assets

The repository's MIT licence applies to original code and documentation authored for this portfolio. It does **not** relicense third-party datasets, pretrained weights, APIs, model assets or other external resources.

Each project should be read together with its own source, provenance and scope notes. Examples include public/government data, historical teaching datasets, public ML benchmarks, public image datasets and pretrained model components. Those resources remain subject to the licences, usage terms and attribution requirements of their original providers.

Where a project uses synthetic or deterministic fixture data, the README/evidence record states that explicitly. Where a project uses historical data, results are not presented as current production performance.

If you reuse a project, verify the current licence and terms for every external dataset/model asset before redistribution or commercial use.
