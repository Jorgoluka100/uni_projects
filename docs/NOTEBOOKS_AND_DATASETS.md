# Notebooks + Datasets — recruiter quick access

Every strengthened project has a Jupyter notebook entry point and an explicit data route. This page is the fastest way to inspect the portfolio without searching through folders.

> **Data policy:** I do not copy large, third-party, licensed or frequently refreshed raw datasets into Git history just to make the repository look full. When raw data should stay external, the project names the exact source and keeps the reproducible download/load route in code. Small fixtures, synthetic data and compact derived evidence are committed where that is the correct engineering choice.
